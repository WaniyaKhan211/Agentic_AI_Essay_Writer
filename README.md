# Agentic_AI_Essay_Writer
An Agentic AI-powered essay writing assistant built with LangGraph and LangChain that transforms rough ideas into polished essays using web search, intelligent evaluation, persistent memory, and AI-generated images.

## Current Progress

Implemented:

- User idea input
- Web research using Exa Search
- Essay generation using Groq LLM
- Essay evaluation using LLM judge
- Pydantic structured output for evaluation
- Automatic retry with feedback until threshold score
- LangGraph workflow
